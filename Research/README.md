# Research

Working notes and reading material. Markdown only — no datasets, no models.

| Folder | Contents |
|---|---|
| `cybersecurity/` | Networking fundamentals, OWASP Top 10, CVE/vulnerability study notes, Kali tool notes |
| `machine-learning/` | EDA techniques, NLP on security text, evaluation methods, study notes |
| `model-experiments/` | Short write-ups of model trials: setup, results, observations — **real results only, never fabricated** |

## Conventions

- One topic per Markdown file, with sources cited (URL + access date).
- Separate **facts from sources** from **our own observations**.
- Experiment notes must record: dataset, model, environment (Colab/local),
  exact metrics, and date — results are never invented or rounded up.
