Before any download:

1. Confirm **license** allows use (and redistribution if relevant)
2. Estimate **size** — anything > 200 MB must be approved first
3. Prefer **streaming / sampling** over full downloads
4. Record provenance (URL, access date, version) in the dataset's README

## Safety note

Any dataset containing real targets, credentials, or personal data must be
handled as sensitive: never commit, never share, never use outside authorized
research scope.
